## 解压到另一目录后验证

从独立项目生成 ZIP，再解压到新的测试位置。解压目录不包含 `node_modules`，使用一个全新的 npm 缓存目录执行：

```sh
npm ci --offline --ignore-scripts --omit=optional --no-audit --no-fund --cache .offline-cache
```

Playwright 和 Playwright Core 均从 ZIP 自带的 `vendor/` 安装成功，没有读取相邻项目的依赖。

在解压目录中完成以下检查：

- 重跑 8 项单元测试和项目引用检查。
- 执行 `python prepare_game.py`，只读取本项目地图、图块集和 `source-assets/`，成功导出游戏场景及精灵图集。
- 执行自然地图生成脚本并检查道路、建筑入口、桥头、坡道和山顶连通性。
- 将服务进程的工作目录设置为系统临时目录，以解压项目自身的 `serve.mjs` 启动服务，仍能正确定位全部资源。
- 使用解压目录自身安装的 Playwright 打开游戏；18 个页面资源请求全部来自该服务，无外部页面资源请求、加载失败或页面错误。
- 在重新导出资源后的解压目录中，完成完整游戏、剑技和手机横屏回归。

详细 JSON 报告及截图保存在 `previews/`。ZIP 排除测试截图和 `node_modules`，保留本记录与可重新运行的全部检查脚本。
