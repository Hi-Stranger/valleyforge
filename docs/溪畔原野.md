# 溪畔原野：参考图重建与环境精修

后续地图沿用本区域的画风、布局和素材制作方式时，先阅读[地图生成规则](地图生成规则.md)，其中包含参考文件、设计约束及可复用提示词。

新增区域 `?region=meadow`。从溪谷镇东南侧原野路标（2420,1200）交互进入，也可从旅人手记的「前往溪畔原野」进入。原野入口交互返回小镇。现有镇区与废矿区域保留。

## 水面与小鱼

按最终确认的加强版预览，游戏水面已加入局部轻微起伏和反光变化，并保留9条装饰小鱼。`game/meadow-fish.mjs` 沿用静水预览中的摆尾、转向、结伴落点和蓝灰/暖褐配色。鱼群只绘制在河流的水面遮罩中，桥、礁石与植物区域被排除；鱼层位于地形之后、桥梁及树木之前。动画使用游戏时钟，暂停时一并冻结，离开镜头时跳过绘制，动画帧按30帧/秒缓存。小鱼不参与碰撞、遇敌、战利品或存档。所需河流素材由现有地图构建脚本导出。

`game/meadow-ripples.mjs` 复现确认的 `wave=2.3` 预览：仅在水面内作少量像素位移、明暗起伏和细波反光，不作向下游整图滚动。效果绘制在小鱼与岸边景物之前，使用游戏时钟，4秒无缝循环，暂停冻结，离开视野时跳过更新，并按30帧/秒缓存；沿岸树木、桥、礁石和植物由遮罩排除。

独立预览可通过 `previews/stream-alternatives.html?fish=1&still=1&gentle=1&wave=2.3` 查看。专项验证覆盖9条鱼游动、鱼与水纹像素位于水面、实心景物静止、4秒无缝循环、视野外跳过、暂停冻结，以及原有跨桥寻路和区域往返。

## 第二版环境精修

本轮只提高地图环境还原度，怪物配置、数值和素材不变；人物继续使用原有模型与头像。

- 用内置 imagegen 重新生成 `terrain-v2.png`、`props-v2.png`、`river-v2.png`，均参考原示例图；旧版源素材保留。
- 草地改用较低对比的橄榄绿与黄绿斑块，扩大纹理尺度；道路按参考布局重做变宽曲线、细碎草缘及棚屋支路连接。
- 河流改为具有岩土断面、浅水、礁石、泡沫和岸边植被的地形。河流源图在构建时与草地合成后切分成32像素图块；现场仍按图块渲染，不使用整图背景。
- 调整树木色调、树冠比例和落点，集中还原中央双树、顶部林缘与底部前景树丛。小花和灌丛集中在树根、石块与河岸周围，保留中间开阔草地。
- 水面碰撞随新版河流重新生成，并保留桥面通行。专项验证已通过全部遇敌点可达、跨桥寻路、区域往返和手机横屏。
- `previews/meadow-environment.png` 是不含人物与怪物的纯环境预览；`previews/meadow-reference-comparison.html` 支持原参考/新版滑动对照、单独查看新版和上一版。`meadow-rebuilt.png` 中的角色已同步为原有模型。

提示词重点：严格沿用参考色彩与像素簇、低噪声草地/土路材质、非霓虹色的独立景物、保留参考位置的透明河流与岩土岸线。当前仍是模块化重建，局部树形与草地细节并非逐像素复制。

## 重建范围

以 `source-assets/meadow/reference.png` 为布局参考，重建 1536×1024 原野：左上蓝顶棚屋、斜向土路、右侧溪流与木桥、中心树丛、左下路标、史莱姆和野猪。参考图中水上的史莱姆调整至东岸可行走地面。

地表纹理、12类景物、史莱姆/野猪及角色前后行走帧使用内置 imagegen 重新生成，源图保存在 `source-assets/meadow/`；不是原图裁剪后充当整张背景。运行时绘制可复用32像素地形块与独立景物，并支持树冠遮挡和树干碰撞。`meadow-ground.png` 仅为导出缓存；现场地图不绘制该整图。

这是按参考布局制作的可玩重建，纹理与物体轮廓不是逐像素复制。人物和头像已按要求恢复为原有素材，沿用原有方向、行走、攻击动画与剑气；生成的新版人物素材仅保留在素材源文件中，不参与现场人物绘制。保留原有战斗、奖励、装备和存档规则。本轮按所选参考图还原，未增加参考图以外的 Boss 洞穴。

## 文件与命令

- `14_溪畔原野.tmj`：地形、独立景物、隐藏碰撞、怪物与入口四层，可在 Tiled 查看和编辑。
- `tilesets/溪畔原野.tsj`、`meadow_assets/`：独立图块与模型图片。
- `tools/build-meadow.py`：可复现的布局和素材构建来源；`npm run map:meadow` 重新生成地图及运行素材，会覆盖该区域生成文件，手工编辑前需备份。当前运行导出以构建脚本为准，直接编辑 Tiled 不会自动进入游戏。
- `game/assets/meadow-world.json`、`meadow-atlas.png`、`meadow-minimap.png`、`arena-meadow.png`：运行数据、图集、小地图和独立战斗地表。
- `npm run test:meadow`：浏览器验证；Windows 使用本机 Edge。
- `previews/meadow-rebuilt.png`：布局总览；`meadow-ingame.png` 和 `meadow-mobile.png` 为游戏截图。

## 生成提示词摘要

使用所选示例图作为风格和布局参考：三格草地/土路/水面纹理；四列三行独立树木、棚屋、桥、路标、岩石、芦苇与花丛；四列四行史莱姆、野猪、角色正面和背面动画。景物另执行一次背景移除，生成真实透明通道。原始生成结果已复制到项目内。
