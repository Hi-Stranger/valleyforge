# 城镇与原野统一渲染、加载优化

版本：v2026.11.01.7。日期：2026-11-01。按用户已确认的方案实施，遵守 [渲染与加载规则](渲染与加载规则.md)。保留两张地图的素材、镜头构图、角色比例、动作、碰撞与存档行为。

## 已实施

- 城镇和原野通过同一静态地面缓存路径绘制，加载阶段每 8 行让出一次执行，准备完成后进入场景。当前地面各为 1536×1024，RGBA 像素估算各约 6 MiB；镜头移动只裁切有效缓存。地形、图集、尺寸或版本变化会使缓存失效，提供显式释放入口。矿洞等地图保留兼容路径，本轮未实现大地图分块缓存。
- 原野水纹与游鱼共用一次地面、水面和景物遮挡读取，初始化整图读回从 6 次减至 3 次。临时 Canvas 清空尺寸；原野地面源图与河流源图在初始化结束后释放，运行水纹保留所需基础像素。水纹、鱼与城镇光效分别保留原来的 30 Hz、30 Hz 与 20 Hz 采样，主画面继续通过 `requestAnimationFrame` 绘制。
- `scene-resources.mjs` 提供页面所有的统一加载入口：规范 URL 和版本、共享同一加载 Promise、最多 4 项并发、等待图像解码、失败移出缓存并允许重试。`releaseImage` 只用于当前场景确认不再使用的专用输入图，共享资源随页面所有者回收。
- 首屏加载公共素材与当前区域必需资源。城镇包含导航素材；原野包含地图中可见的野猪王动作。两图首屏不等待战斗或技能演示背景，也不加载无关山地、洞穴战斗背景。
- 首屏完成后延迟 1.5 秒低优先级准备当前区域背景。城镇使用原有林地演武背景，原野使用其实际战斗背景；同一背景由技能页与战斗复用。尚未准备完时先显示提示；战斗尚未创建、计时或结算，资源就绪后才进入原有战斗流程。演武依赖在技能页使用前等待，属性页可直接打开。
- 加载显示资源完成项与地面准备阶段。背景失败可原地重试；首屏失败沿用重新加载按钮。关闭技能面板后，旧任务不能重开面板；离开页面后忽略旧结果。小地图弹窗与战斗地图复用已加载的带版本地址。
- 跨区域仍采用整页跳转，使用浏览器 HTTP 缓存。非 BFCache 的 `pagehide` 取消队列和可取消任务，释放页面持有图像、地面及效果缓存；BFCache 中的页面保持暂停并供浏览器恢复，`pageshow` 重置帧间隔。当前并未实现跨页常驻资源池、相邻地图预取或全站内存上限。

## 验证

| 检查 | 结果 |
| --- | --- |
| 每张地图预热后连续移动镜头 120 次 | 地砖重拼 0 次，缓存尺寸重设 0 次 |
| 原像素尺寸、不同视口地面裁切 | 与旧地面绘制逐通道一致 |
| 水纹及游鱼 12 个动画时刻 | 像素一致，游鱼位置一致；整图像素读回 6 → 3 |
| 固定随机种子与游戏时刻的完整实机画面 | 城镇、原野各在 1536×1024 与 932×430 比较，四组画面差异像素均为 0 |
| 加载与失败 | 首屏无战斗背景依赖；慢演武加载后关闭、失败重试、慢战斗准备和重试通过 |
| 生命周期 | 限流、去重、取消队列、卸载清理、四次区域往返与加载中快速离开通过 |
| 原有功能 | 城镇三项服务、NPC 动作与萤火虫、暂停、原野水面与桥梁、遇敌、存档、矿洞和原区域兼容检查通过 |

复现命令：`npm run test:rendering`、`npm run test:loading`、`npm run test:town`、`npm run test:meadow`、`npm run test:town-camera`、`npm run test:town-effects`、`node tools/verify-retained.mjs`、`npm test`、`npm run test:assets`。

临时报告位于 `previews/unified-rendering-validation.json`、`previews/unified-loading-validation.json` 与 `previews/unified-visual-validation.json`；同镜头对照为 `previews/unified-<town|meadow>-<native|mobile>-comparison.png`。水面优化前实现保留在 `tools/fixtures/`，供像素对照使用；预览目录中的完整旧版截图工具仅为本轮临时验证。

主循环采样报告包含桌面 Edge 932×430 下每区域 120 个探索帧的回调耗时与帧间隔，并记录本地首次进入和再次进入耗时。这些数据不包含完整 GPU 合成成本，不是手机 FPS，也不能将本地服务器测试解释为移动网络加载速度。RGBA 像素占用仅为估算；多次往返验证的是当前页面资源持有数量，不能据此宣称浏览器全进程内存恒定。真实手机帧率、峰值内存与长时间游玩仍需真机复测。
