# 怪物展示规则

生效版本：v2026.10.30.8。用户最新明确要求优先。

- 普通怪物与精英没有怒气值，不增加怒气逻辑，也不展示怒气条或怒气数值。
- 小怪头顶生命条沿用 Boss 的生命条样式：红色填充（#b95249）、低调半透明未填充底色（#39261e99），居中显示“当前生命 / 最大生命”，满血也展示。
- 不展示头顶名称，不加外围黑框、卡片底或阴影。名称仍可用于遇敌说明、地图面板和结算。
- 生命条按每帧实际坐标、镜头和震屏跟随移动，置于角色头顶，避免画面边缘裁切；暂停时冻结，不拦截操作。
- 探索时沿用靠近显示范围（135 世界单位）；独立战斗中持续显示，怪物死亡或离开战斗后移除对应血条。
- 采用已确认的紧凑比例：小怪与精英桌面宽 72px、高 8px，手机（视口宽不超过 1000px）宽 56px、高 7px，数值字号均为 8px。颜色与排版沿用 Boss，尺寸小于 Boss。
- Boss 的生命与独立怒气展示继续遵守 [Boss 规则](Boss规则.md)。Boss 桌面双条宽 120px，手机双条宽 96px；详细高度与字号见 Boss 规则。
- 所有怪物击败后返回地图立即满血刷新，无需等待或远离；保留返回地图后的短暂遇敌保护。
