# 溪谷营地 · v2026.11.01.5

当前 `?region=town` 已接入确认的夜景露天营地：中央火堆与木凳，左侧铁匠、右上药剂法师、右下杂货商。锻造、武器与防具合并为一个服务点；装备打造、药水补给和材料寄存恢复原有规则；不包含强化、职业、六章任务或材料出售。玩家仍使用既有模型，木凳上的沉思剑客是场景 NPC。

## 当前素材与构建

- 世界尺寸 1536×1024，32px 地表网格。入口 `(768,838)`，右上原野出口 `(1425,178)`。
- `source-assets/town/camp-v1/` 保留确认预览、独立动画源图与背景素材。`layout.json` 记录景物轮廓、深度、脚部碰撞、三个交互点及动画锚点。
- `tools/build-town.py` 当前调用 `tools/build-town-camp.py`；旧版 `build-town-native.py` 与原始素材保留为历史，不再作为默认营地构建源。
- 背景中的景物按语义轮廓提取为独立透明物件；地表排除这些景物，被遮挡地面使用可复用草地、土路材质。游戏加载图块数据与透明图集，不请求概念整图。
- `game/assets/town-world.json`、`town-atlas.png` 与 `town-minimap.png` 是运行导出；小地图不作为游戏唯一背景。
- 树干和景物脚部阻挡，树冠允许遮挡；火堆、木凳、药锅和货车有脚部碰撞。旧城镇越界存档会回落到新入口，装备、材料及成长数据保留。

## 手机镜头移动缓存

v2026.11.01.5 仅对新营地启用固定地表缓存。首次绘制时从可编辑图块数据组装 1536×1024 的地表画布（RGBA 约 6 MiB），镜头移动只从缓存取景，不按可视图块边界反复重拼和重设画布。人物、景物、动画及其他地图原绘制方式保留；素材、地图结构或 `terrainRevision` 变化会重建缓存。

`node tools/verify-town-camera.mjs` 对照原绘制器验证 120 帧镜头移动：原版图块绘制 22,512 次、画布尺寸设置 40 次；新版初始化 1,536 次、设置尺寸 2 次，其后移动过程中两者均为 0。原像素尺寸图像完全一致；手机小数缩放下因最近邻采样边界产生的差异低于比较像素的 0.1%，无透明接缝。此项为桌面 Edge 绘制工作量检查，不代表真实手机 FPS 测量。报告：`previews/town-camera-validation.json`。

## 动画与演示

`game/town-camp.mjs` 使用游戏时钟驱动三套各八帧的人物动作：铁匠抬锤、落锤与回弹；巫师双手带动搅拌杆；剑客慢呼吸、垂首与扶颌沉思，不双手合十。药锅分前后层，搅拌杆在液面可见，浸入部分被锅壁遮挡。附加局部火光、火星、气泡、烟气和 12 只缓慢飞行的萤火虫。动画只绘制视野内内容，暂停、菜单和竖屏时跟随游戏时钟冻结。

确认演示已归档：[营地动态与人物动作](media/town/camp/README.md)。剑客已按后续确认图改为旧皮甲、灰绿披风、朴素佩剑和简化像素五官，一手扶颌、一手搭膝，双脚自然垂下。八帧保留慢呼吸、低头停顿和轻微抬眼。此前深色长袍源图保存为 `hero-wuxia-v1.png`，不再参与运行。

## 当前验证

`npm run test:town` 检查三个服务点的真实寻路与交互、合并打造、补药、材料寄存、脚部碰撞、旧坐标恢复、区域往返、八帧动作、萤火虫、暂停与横屏/竖屏。结果写入 `previews/town-validation.json`。

## 地图与素材

世界尺寸 2560×1152，地表网格 32px。五间独立商店沿街横排、保留间隔与可通行侧巷；左侧锻造铺保留可见侧墙和开放工坊的斜角。图像是按确认图制作的独立素材，实机由模块化地表、商店、树木和角色组合，不把概念整图作为背景，也不机械切割概念整图。

- `source-assets/town/extracted-v3/`：直接从确认原图提取的独立商店、树丛、灯柱、围栏、花草、铺路石及导航图标与文字。
- `source-assets/town/extraction-v3.json`：每件原生物件的轮廓多边形、尺寸、位置、脚部深度及遮挡区域记录。
- `tools/extract-town.py`：原图提取与 alpha 遮罩构建来源；遵循地图规则的直接提取要求，不重新生成已有可见物件。
- `source-assets/town/*-v2.png` 和 `tools/build-town-v2.py`：旧版独立生成素材及构建脚本，仅作历史保留。
- `game/assets/town-nav-icons.png`：铁砧、剑、盾、药水和袋子的 5 格图集，替代 Unicode 字符。
- 地表：先排除建筑、树木、人物及导航，提取可确认的裸露草土纹理与材质分布；被遮挡的地面用可复用草土材质填补。地图之外的延伸区域也使用这些材质。
- 原始参考整图只在构建时读取，不作为运行背景或运行图片请求。地表图集不包含建筑、树木、人物或导航画面。
- `tools/build-town.py`：调用 `build-town-native.py` 和提取脚本，负责地表、独立物件、交互和碰撞的构建。依赖 Pillow、NumPy 与 OpenCV。`npm run map:town` 会重新导出运行资源及布局摘要，覆盖前需保留手工修改。
- `source-assets/town/layout.json`：可读的尺寸、商店交互点、碰撞和出入口摘要，构建时生成；直接编辑此摘要不会改变运行地图。
- `game/assets/town-world.json`：可编辑的图块层、景物层、脚部碰撞、商店交互点与入口出口运行数据。
- `game/assets/town-atlas.png`：图块与独立商店图集；`town-minimap.png` 仅用于地图界面，现场不绘制整幅背景。

图集保留透明通道，景物按脚部深度排序，沿用原有角色素材与移动动画。以 1774×887 为构图基准，三间主要店铺的可见轮廓左边界分别为 0、714、1142，交互点位于门前开放道路；相机保留近距离斜俯视。招牌是建筑素材的一部分，移除悬浮店名与额外铁匠人名。玩家保留现有模型与动画，城镇专用显示比例按确认图调整，原野与战斗比例不变。

建筑、招牌、陈列、树丛、围栏、灯柱及花草保留原图像素与位置。地表按语义遮罩提取裸露材质，保持可编辑图块层；树木和建筑不烘焙进地表。

明确的源图信息边界：左侧导航覆盖 x=24–184、y=260–607；该处无法取得原始无遮挡像素，使用近似反透明度和邻域修复。当前画框以外的药铺右侧与杂货店保留旧版扩展素材。现有玩家模型与原图人物不同，沿用项目人物规则；全画面不宣称逐像素一致。

## 商店和导航

左侧半透明导航仅在城镇正常探索中显示；暂停、弹窗、转为竖屏和离开城镇时隐藏。锻造、武器、防具、药铺、杂货按钮调用现有碰撞感知寻路，到门前后点击交互或按 E；不瞬移、不自动打开店铺。手动移动可中断寻路。

- 锻造铺：沿用所有现有装备配方。
- 武器店、防具店：按武器、护甲分类展示现有打造与穿戴功能；没有增加金币购买装备的价格体系。
- 药铺：复用现有药水补给，每瓶 12 金币，上限 99。
- 杂货店：查看随身和仓库材料，并沿用材料寄存功能；没有新增材料买卖价格。

城镇无怪物、Boss 或战斗血条。原野的独立即时战斗、奖励、怪物配置与水面效果保留。

## 验证

`npm run test:town` 验证五店寻路、店体碰撞、分类打造、药水购买、材料寄存、城镇与原野往返、存档保留、手机横屏和暂停隐藏导航。实机截图为 `previews/town-desktop.png`、`previews/town-mobile.png`，结果为 `previews/town-validation.json`。`previews/town-scene-review.png` 为临时隐藏通用 HUD 的实机对照截图；正式运行仍保留通用 HUD。

`npm test` 验证装备、存档和战斗单元逻辑；`npm run test:meadow` 验证原野素材、桥梁、遇敌、水面、区域往返与手机横屏。

修正目标与实际场景可在 [左右对照页](../previews/town-restore-comparison.html) 拖动比较。本轮使用确定性的原图提取流程，不使用 imagegen 重绘可见店铺。`tools/verify-town-visual.py` 对三个店面内部区域做逐像素检查，结果与全画面差异分别记录于 `previews/town-visual-validation.json`；核心区域检查不能代替整图人工验收。
