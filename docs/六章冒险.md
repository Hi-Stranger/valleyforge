# 六章冒险 · v2026.11.01.1

本版本在 `feature/complete-rpg-progression` 分支延续溪谷铸途：从 Lv.1 成长至 Lv.60，使用剑士、枪手或圣职者，探索六个战斗区域，完成六章主线与区域委托，采集、打造、强化并培养技能。采用现有手机横屏、俯视角探索与独立即时战斗。

## 职业与技能

| 职业 | 玩法 | Lv.15 转职方向 |
| --- | --- | --- |
| 剑士 | 近战连击、位移、打断和剑阵 | 御剑者 / 铁壁卫士 |
| 枪手 | 真实弹道、散射、爆破和机炮 | 游击枪手 / 重炮专家 |
| 圣职者 | 圣光输出、治疗、护盾和祝福，可独立完成冒险 | 祈光使 / 裁决者 |

职业结构参考 DNF 的职业分工、技能树、转职与觉醒思路，具体技能与俯视角实现为本项目设计。职能参考：[DFO 枪手介绍](https://www.dfoneople.com/gameinfo/character/Gunner%28M%29)、[DFO 圣职者介绍](https://www.dfoneople.com/gameinfo/character/Priest%28F%29)。

每个职业有 9 个主动技能，两条转职方向各有 2 个专属技能，共 27 个主动技能。当前转职可以使用 4 个通用技能、2 个转职技能及 1 个觉醒，在其中自由选择 4 个装配到按键 1–4。点击头像进入技能树，升级或选择装配位置。

新角色在 Lv.1、5、10、20 开放基础技能，Lv.15 转职，Lv.30 和 40 开放转职技能，Lv.50 开放觉醒，Lv.60 获得职业精通。觉醒需要已选择转职。旧版剑士保留已有四招，不会因为新等级门槛失去原先技能。

每次升级获得 1 SP，满级共 59 SP。普通技能升级每级 1 SP，最高 10 级，并受人物等级限制；觉醒最高 3 级，每次升级 3 SP，在 Lv.55、60 开放后续等级。技能等级提升伤害；治疗、护盾和祝福也按技能等级成长。在溪谷镇可以免费洗点和更换转职，更换转职会返还 SP 并恢复该职业四个通用技能槽。

枪手普通攻击与技能通过移动弹体和线段扫掠判断命中；贯穿弹同次攻击不会重复伤害同一目标。圣职者的辅助技能作用于当前角色，治疗不超过生命上限，护盾有持续时间。机炮、剑阵、轰炸与圣域可以在施放后独立运行。

## 区域与材料

| 区域 | 推荐等级 | 主要成长材料 | 首领 |
| --- | --- | --- | --- |
| 溪畔原野 | 1–10 | 木材、凝胶、兽皮、兽牙 | 荒牙野猪王 |
| 废矿深窟 | 11–20 | 铁矿、骨片、晶石 | 晶岩巨像 |
| 幽苔森林 | 21–30 | 灵苔 | 古树灵鹿 |
| 赤砂荒原 | 31–40 | 赤琥珀 | 赤砂蝎王 |
| 霜脊雪岭 | 41–50 | 霜晶 | 冰川巨灵 |
| 余烬裂谷 | 51–60 | 余烬石 | 余烬古龙 |

溪谷镇作为安全中心。点击右上地图图标，打开世界区域页；在城镇或区域入口可以旅行。达到推荐等级，或完成前一章，均可开放下一地区。原野已补充木材采集点；已有矿谷恢复独立访问。新四区各有独立景物、可绕行道路、过水桥梁、资源、普通怪、精英和首领地标。

当前地图页可以点击寻路。手记和 R 可引导返回区域入口，移动和受伤会中断返回；入口 E 打开世界旅行。接触怪物进入独立即时战斗。战斗结束恢复技能冷却，胜利只结算一次奖励，返回地图后怪物满血刷新。

新增 17 种怪物定义，包括五位新首领。普通敌人包括苔芽精、织影蛛、赤砂甲虫、流砂掠夺者、霜牙狼、冰原灵火、灰烬小鬼和焦土哨兵；各区还有精英守卫。远程怪物会先显示方向预警再发射可躲避弹体。普通与精英只有战斗血条；首领有独立怒气与战斗双条，继续遵守已有的紧凑显示规则。

## 任务、打造与强化

六章各有四步：抵达区域、击败八次怪物、累计收集六份主要材料、击败区域首领。目标完成后自动领取一次奖励，奖励随章节成长。累计收集独立于当前剩余数量，打造扣料不会倒退任务。每个区域另有可重复委托，每击败六次怪物可从手记领取一次经验与金币。

装备共 36 件，其中 3 件为职业初始武器、33 件可打造。保留原有六配方与特色，新增职业武器及后续阶段护甲、饰品。打造页按职业和店铺类型筛选，显示等级要求、材料来源、随身与仓库总量。强化上限 +10，每级提升基础属性或饰品效果 4%，必定成功，消耗金币和材料；扣料前检查完整成本，失败不消耗。

武器、防具店继续提供分类打造，药铺提供补给，杂货店支持寄存与出售随身材料。新材料均来自对应区域的实际怪物或采集点。人物页展示装备、等级、强化和转职共同计算后的真实属性。

## 存档

沿用 `valleyforge-save-v1` 活动存档和数据格式版本 1，旧档自动补全职业、技能、强化和章节字段，保留装备、材料、金币和等级。每个职业另存于 `valleyforge-character-<job>`；在溪谷镇人物页切换角色，三个角色分别保留进度。相同浏览器和访问地址才能读取同一组存档。

存档包含当前区域和安全探索位置；战斗中保存遇敌位置，刷新不会发放未完成战斗的奖励。更换转职及洗点不重置章节或装备。不得把 QA 验证会话当作实际游玩存档。

## 新地图编辑与素材

新地图为 2048×1280、32 像素网格。`maps/forest.tmj`、`dunes.tmj`、`frost.tmj`、`rift.tmj` 保留地形、景物与遇敌、碰撞、采集点和入口对象层。运行数据为 `game/assets/<region>-world.json`。

`game/adventure-world.mjs` 是当前生成布局与地形的来源，`game/adventure-art.mjs` 提供独立像素景物、职业和怪物动作绘制。地表材质复用项目内 `source-assets/meadow/terrain-v2.png`，原野树木与岩石继续使用原图集，按区域做材质处理。运行时使用去重的地形图块、独立景物及脚部碰撞，未把概念整图作为运行背景。

`npm run map:adventure` 重建新四区的图块图集、总览、独立战场、运行数据和 Tiled 文件，执行会覆盖这些生成文件。手工编辑 Tiled 后需同步布局生成源；当前没有把 Tiled 改动反向导入生成源的流程。动作绘制在原生小像素画布中缓存，再以最近邻放大，包含行走、抬头、跺脚、跃起、落地和收势姿态。

## 验证与开发命令

- `npm test`：装备、扣料、等级 60、旧档、SP、转职、技能槽、强化、弹道、辅助效果与 Boss 状态机。
- `npm run test:rpg`：七个区域、四张新地图的资源与通行、矿谷进出、六首领奖励防重、角色切换、打造强化、读档、手机横屏及双指操作；另验证 27 个技能的实际战斗效果。
- `npm run test:skills`：原有四剑技伤害、消耗、冷却、暂停、竖屏和小屏按钮布局。
- `node verify-fluid-controls.mjs`：原有移动施法、输入衔接和闪避取消。
- `node tools/verify-rpg-campaign.mjs`：从一级新档出发，使用正常旅行、采集、拾取、打造与奖励路径完成六章并到达 60 级。此项使用 QA 加速击败敌人，实际技能伤害由另一项独立验证。
- `npm run test:assets`：检查活动项目本地引用；历史备份和发布快照不作为当前构建依赖检查。
- `npm run boss:demos`：重新录制并归档五个新首领技能 GIF。

浏览器验证使用独立会话与临时端口。横屏与触摸验证采用桌面 Edge 的移动模拟，不能代表真实手机帧率。历史单区域验证脚本仍有旧界面与区域假设，六章系统以本页列出的命令为当前验证入口。
