# Boss 设计与战斗规则

生效日期：2026-10-30。以已确认并接入实机的荒牙野猪王为基准，当前基准版本为 `v2026.10.30.4`。

后续在本项目设计、生成素材、实现或修改 Boss 时，默认遵守本文。用户最新明确要求优先；本文不授权自动改造现有地图、替换素材、提交 Git 或发布游戏。

## 1. 默认继承与适用范围

- 新 Boss 默认沿用“距离选择攻击、独立怒气、明确动作预警、可闪避、攻击后可反击”的战斗结构，以及本文规定的头顶双进度条样式。
- 荒牙野猪王的机制与下表参数作为默认模板；新 Boss 未指定参数时以此为起点，不自行改成另一套战斗结构。
- 外观、动作题材、数值、掉落和刷新位置可随用户指定的 Boss 主题调整。不要把其他 Boss 都画成野猪，也不要未经要求批量修改现有 Boss。
- **对 Boss 的任何修改，都必须先出视觉预览，不能直接修改实机代码。** 包括外观、动作、技能、攻击条件、数值、怒气、进度条、预警、遇敌、奖励、刷新及相关交互。
- 预览形式视内容选择静态图或 GIF：外观、布局和样式通常使用静态图；动作、技能过程和战斗节奏通常使用 GIF。选择足以清楚表达本次变化的形式，不强制同时展示静态图和 GIF；确有必要或用户明确要求时再同时提供。
- 预览阶段只制作独立预览、临时演示或说明，不得先改实机代码、运行数据、正式素材、地图配置或发布目录，再把结果当作待确认的预览。
- 预览交付后，必须等待用户明确确认并要求实施，才能修改对应代码和正式资源。仅提出修改需求、说“调整一下”或“直接改”等，不能代替查看该方案预览后的确认。
- 用户已看过并确认当前方案、随后要求“修改”或“实现”时，可直接实施已确认的范围，不重复要求确认；实施中若新增或改变方案，先为变化部分出预览并等待确认。
- 优先查看现有代码和项目内动作图集。预览是设计参考，不代表功能已经接入代码。

## 2. 按距离选择攻击

距离以双方脚底中心的世界坐标计算，不使用屏幕像素；镜头缩放不能改变攻击条件。

| 距离 | 默认攻击 | 触发方式 | 野猪王当前模板 |
| --- | --- | --- | --- |
| 近距离 | 吼叫 | 玩家靠近时由 Boss 主动随机触发，不要求满怒 | 距离不超过 115；每次判定 80% 概率；抬头蓄力 0.6 秒后造成 122 半径范围伤害，基础伤害 14 |
| 中距离 | 跳跃扑击 | 玩家在中距离时随机触发，不要求满怒 | 距离大于 115、不超过 290；每次判定 50% 概率；压身蓄力 0.6 秒、腾空 0.75 秒；落地 55 半径，基础伤害 18 |
| 长距离 | 冲撞 | 必须怒气满，不能绕过怒气条件随机发动 | 距离大于 290 且怒气达到 100；先跺脚两次，蓄力 1.2 秒；最后 0.3 秒锁定方向；速度 520，最多持续 1.1 秒，基础伤害 26 |

- 随机判定必须有时间间隔，不能每帧重试导致实际必定出招。野猪王当前间隔为 0.9–1.4 秒。
- 判定未触发时允许观察、缓慢接近或等待；保留玩家识别节奏和走位的时间。
- 近、中距离即使满怒，也按对应距离选择攻击；长距离且满怒后才选择冲撞。
- 同一时间只执行一个攻击状态，不能在跳跃或冲撞途中突然切换另一种攻击。

## 3. 怒气与战斗状态

- Boss 有独立怒气值，初始 0、上限 100。默认自然缓慢增长，受到实际攻击后快速增长；野猪王当前自然每秒 +3，每次受击 +12，并限制在上限内。
- 吼叫和普通跳扑不消耗怒气。冲撞发动时清空怒气；当前模板在冲撞和收势期间暂停自然增长，实际受击仍可增加怒气。
- 怒气与攻击逻辑共用游戏时间。暂停、战斗面板、手机竖屏或页面后台时，不得继续积累怒气、推进动画、造成伤害或偷跑冷却。
- 重新进入战斗时，重置怒气、攻击状态、锁定目标、命中标记、跳跃高度及临时动作状态，不继承上次撤离或失败时的怒气。
- 保留出招间隔与攻击后收势。冲撞结束后默认喘息 2.2 秒，提供明确的反击窗口。

## 4. 必须有实际动作与可读的攻击预警

- 使用与现有地图、人物一致的二维斜俯视像素风，保持像素尺度、配色、体量与当前游戏画面协调。
- Boss 必须有真实逐帧姿势变化。不能用一张静态贴图平移、旋转或上下抖动来代替跑动、吼叫、跺脚、跳跃和冲撞动作。
- 跑动要有四肢交替蹬地、身体起伏；吼叫要抬头张嘴；冲撞前先抬蹄跺地，再低头疾跑；跳扑要有压身、蹬地起跳、空中姿势、下降、落地和收势。
- 同一 Boss 的不同帧保持身份、配色、装备、体型与锚点一致，使用真实透明背景，不把地面或界面画进角色图集。
- 动作与伤害时机一致：吼叫在蓄力后命中，跳扑在落地时命中，冲撞在实际移动路径上命中，不能在预警阶段提前造成伤害。
- 跳扑锁定合法落点，给出落地范围；不能落到水中、实心障碍或不可通行区域。冲撞给出方向预警，最后一段锁定方向，玩家可侧向闪避；遇墙或障碍提前结束。
- 地面预警清晰、克制，不遮住玩家、落点或操作按钮。动作 GIF 应能看出起手、攻击、躲避及收势过程。

## 5. 血条与怒气条的最终默认样式

- 两条进度条跟随 Boss 头顶：上方红色生命条，下方橙色怒气条，保留各自数值。满怒时可用更鲜明的暖红色强调。
- **不显示头顶 Boss 名字，不加外围黑色面板、卡片底、外框或阴影。** 允许进度条未填充部分使用低调半透明底色，以便阅读剩余比例。
- 已确认的紧凑尺寸（v2026.10.30.8）：桌面双条宽 120px，生命条高 10px、字号 9px，怒气条高 8px、字号 8px；手机（视口宽不超过 1000px）双条宽 96px，生命条高 8px，怒气条高 7px，字号均为 8px。双条间距 2px。小怪尺寸另见 [怪物展示规则](怪物展示规则.md)。
- 不恢复屏幕顶部固定的大首领条，不在头顶重复显示名称或额外状态卡片。
- 跟随位置按 Boss 的实际坐标、跳跃高度、镜头和震屏每帧更新，不能只随地面位置移动，也不能只按数值刷新频率更新位置。
- 保持头顶适当间距；画面边缘避免切掉进度条，Boss 离开视野或战斗结束后隐藏。暂停时跟随条冻结。
- 手机横屏仍清晰可读，不遮挡菜单和技能，不拦截移动摇杆、地图点击或攻击触控；提示消息避免盖住进度条。
- 本条只规范 Boss 头顶战斗展示，不禁止地图标记、遇敌提示、任务或结算中出现 Boss 名字。

## 6. 遇敌、伤害、结算与刷新

- 保留“大地图靠近 Boss → 进入独立即时战斗 → 返回遇敌地点”的结构。探索地图不直接结算双方战斗伤害。
- Boss 刷新点必须可到达，留出接近和绕行空间，不能让玩家从安全入口出生后立即被迫触发首领战。
- 同步地图运行数据、Tiled 遇敌点和构建脚本，重新生成地图不能丢失 Boss 或因缺少动作索引导致构建失败。
- 吼叫、跳扑落地每次攻击只结算一次伤害；冲撞用路径线段检测避免穿过玩家却漏判，同次冲撞最多命中一次。沿用防御、闪避无敌、药水、死亡和撤离规则。
- 野猪王当前允许重斩及带打断效果的剑技打断吼叫、跳扑起手；腾空和怒气冲撞不因普通受击中断。动作期间不能被普通受击或剑阵牵引意外改写锁定路径。
- 胜利奖励只能结算一次；失败和撤离不给首领奖励。返回地图、死亡复活、重复打开界面不得重复发奖励。
- 野猪王当前为 650 生命、20% 护甲减伤；奖励为 120 金币、220 经验、首领核心 1、晶石 4、铁矿 6、兽皮 5、兽牙 4。不要把这些数值当成所有 Boss 必须相同的平衡值。
- 当前调试刷新规则（v2026.10.30.6）：所有怪物（含精英与 Boss）胜利后返回地图，立即在原出生点满血重生，无需等待或远离；保留返回后的短暂遇敌保护。更换刷新规则须与地图提示、实现说明和验证同步。
- 不为接入 Boss 改坏存档、装备属性、普通怪物、地图寻路或既有四个剑技。

- 机制修改：`npm test` 和 `npm run test:boss`，覆盖距离边界、随机间隔、怒气增长与消耗、单次伤害、闪避、收势和重入重置。

- 地图或遇敌点修改：`npm run test:meadow`，确认首领可达、普通怪与跨桥寻路正常。
- 涉及技能交互：`npm run test:skills`，确认剑技真实伤害、打断和冻结行为。
- 代码修改遵守[编码规则](编码规则.md)，提升游戏版本并同步相关缓存参数；概念预览、实现、提交与线上发布需如实区分。
